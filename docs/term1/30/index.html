Lesson 30: Notating melody over the progression

Learning intention

  • flat.io
  • Faulty file for correction
  • Note entry drill sheet

LearnGetting the rhythm right on the page

A melody you can sing but cannot write down is not notation yet. Getting it onto the page correctly matters because someone else, including you in six months, has to be able to play it back from the symbols alone.

The usual errors

  • Wrong rhythm values. A note held for the wrong length looks fine on the page and sounds wrong the moment it is played back — check note values against what you actually sang, not what looks tidy.
  • Missing rests. Silence is part of the rhythm. Leaving a rest out shortens every note after it by the same amount, and the error compounds the further you go.
  • Ties across the beat. A note held over a barline or across a strong beat needs a tie, not a single note value that happens to be the right length.
  • Melody against the chord. Check the notes you have written actually sit inside or make sense against the chord underneath at that bar. If they clash and you did not mean them to, you have probably written the wrong note, not found a deliberate dissonance.

The check is always the same: play it back and listen for the gap between what you meant and what you actually wrote. That gap is where the missing beats are hiding.

Worth keeping

Notation is a message to a player, so it has to be right.
